## Converging plan
1. **Positioning:** progress journal + feedback between lessons for adult learners (figure + hockey), not "AI coach". Coaches as distribution.
2. **Data engine:** declare-then-verify tagging (shipped locally 2026-09-19), AI suggestions confirmed/corrected by users, paid Coach Check reviews = gold labels, adult shot-list filming.
3. **Capture:** request 60 fps + read true fps (days); slo-mo import path; native 120 fps module (weeks); on-device event finding → upload short bursts.
4. **AI:** v1 motion bursts + skater crop + cached guide + "unsure" (keeps Claude); v2 server pose (RTMPose/ByteTrack, Apache/MIT); v3 own model on own labels.
5. **Validate demand in 2 weeks:** landing page + ~$500 ads ($59/yr founding pre-order), free critique thread, 30 free coach seats.
